# Bug Triage Playbook

## 概要
バグを再現・分類・修正するための標準手順。

## 前提条件
- テストスイートが存在すること
- バグの再現手順またはエラーメッセージが提供されていること

## 手順

1. **バグの再現**
   - エラーメッセージ / スタックトレースを収集する
   - 最小再現ケースを作成する
   - `pytest` または適切なテストコマンドで再現を確認する

2. **根本原因分析**
   - コードベースをセマンティック検索してバグ箇所を特定する
   - 関連するコミット履歴を調査する

3. **修正の実装**
   - 最小変更の原則で修正を実装する
   - 修正前にテストケースを追加する（TDD）

4. **検証**
   - 全テストが通ることを確認する
   - 回帰テストを実行する

5. **PR作成**
   - `fix: <バグの説明>` の形式でコミット
   - PRにバグの説明・根本原因・修正内容を記載

## 完了基準
- [ ] バグが再現できなくなった
- [ ] 既存のテストが全て通る
- [ ] 新しいテストケースが追加された
- [ ] PRが作成された
