# Code Review Playbook

## 概要
コードレビューを体系的に実施するための手順。

## 前提条件
- レビュー対象のPRまたはブランチが存在すること

## レビューチェックリスト

### セキュリティ
- [ ] SQLインジェクションの脆弱性がないか
- [ ] XSSの脆弱性がないか
- [ ] 認証・認可が適切か
- [ ] シークレットがハードコードされていないか

### コード品質
- [ ] 型アノテーションが付いているか
- [ ] エラーハンドリングが適切か
- [ ] ログ出力が適切か
- [ ] 重複コードがないか

### テスト
- [ ] 新しいコードにテストがあるか
- [ ] エッジケースがカバーされているか

### ドキュメント
- [ ] 公開APIにdocstringがあるか
- [ ] READMEが更新されているか（必要に応じて）

## 完了基準
- [ ] 全チェックリスト項目が確認された
- [ ] Severe Bugが0件
- [ ] レビューコメントに返答した
